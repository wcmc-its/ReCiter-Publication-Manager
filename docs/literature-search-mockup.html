What changed after the systematic-review conversation

  1. Screen 2 Mode 1's deliverable is the search strategy — not records, not a synthesis. For a systematic review, the strategy is the librarian's intellectual output: peer-reviewed by another librarian, published as the PRISMA-S appendix, and the thing that makes the review reproducible. Records, screening, and synthesis belong to Covidence and Rayyan, which the SR team already trusts. So Search-strategy mode has no candidate list, no screening checkboxes, and no synthesis. It is a much smaller screen than the previous draft — and it's the one they'd actually use.
  2. Screen 2 Known-item validation, and it isn't optional. The librarian names papers the search must find; we report hit or miss for each. Without it, the failure mode is a model emitting a confident, plausible Boolean that silently misses half the literature with nobody able to tell. The miss is styled as the most important thing on the page, with the model's guess at why — because that's what tells the librarian how to widen.
  3. Screen 1 The result cap is gone from Search-strategy mode. An earlier version of this mockup proposed refusing above 200 records. That was wrong: SR searches are designed to over-retrieve, so the tool would have refused to run on essentially every real systematic review. The cap is a property of the mode, not a global setting — Mode 1 doesn't synthesize, so no abstracts enter a context window and there is nothing to protect. Issue review and Clinical question keep the 50-cap.
  4. Screens 1 & 2 Built for Embase and Scopus without building Embase or Scopus. Phase 1 is PubMed-only, but the query artifact is an array keyed by database, and hit counts render per database rather than per sub-query. Adding Embase later pushes an element; no consumer changes. The greyed-out database rows are deliberate — they hold the shape open. No abstraction layer, no adapter interface, and no query-translation engine: the model writes a native query per database.
  5. Sidebar “Literature Search”, open-book icon, slotted after Create Reports. Unchanged. Two-word Title Case like every sibling, drawn in the existing 16×16 stroke-1.5 NavIcon idiom so it sits beside the others without looking imported.
  6. Still open How loudly do we say “this is not a systematic review tool”? Mode 1 now structurally can't emit a synthesis, so the hazard is much reduced. The mockup takes the middle option — one quiet line under the mode picker naming the handoff to Covidence. A first-run banner is the alternative, but your SR librarians may find it patronising. Worth asking them.

Colours, spacing, and radii are the calm tokens from styles/globals.css on origin/dev, not re-derived. Type is the app's own --font-sans stack rather than an embedded webfont, so it falls back exactly the way RPM itself falls back.
